### MCP 材料计算智能体工具包（VASP-MCP）用户指南

本指南面向最终用户，帮助你用自然语言驱动材料计算工作流（结构优化、SCF、DOS、MD），无需了解底层实现细节。你只需在支持 MCP 的智能体/IDE 中与“VASP-MCP”对话即可完成从任务提交到结果获取的全流程。


## 你可以用它做什么
- **结构优化（Structure Optimization）**：基于化学式或 CIF，筛选并优化晶体结构，为后续计算打基础。
- **自洽场计算（SCF）**：在优化后的结构上精确收敛电子结构，为 DOS/MD 提供输入。
- **态密度（DOS）计算**：得到总/分波态密度及可视化分析。
- **分子动力学（MD）计算**：支持单温度或多温度扫描，输出动力学与稳定性分析报告。
- **任务管理**：随时查询进度与结果、列出历史任务、取消排队或运行中的任务。
- **INCAR 参数指引**：获取常见自定义 INCAR 参数的简明说明与示例，按需高级定制计算。


## 适用场景
- **筛选与评估材料候选**：从已知化学式快速得到稳定结构、能带/带隙、DOS 等核心指标。
- **高通量/批量工作流的对话式编排**：通过对话把结构优化→SCF→DOS/MD 串起来，减少手工往返。
- **快速复现实验条件**：用自然语言描述温度、步数、精度等级等条件，快速复现实验/文献设置。
- **报告产出**：自动生成 HTML/图片/JSON 等结果，便于汇报与二次分析。


## 如何与智能体对话
下面给出通用的“提示词模板”。参数都是可选的，能说人话就尽量说人话；当你清楚参数名时也可直接点名。

- **提交结构优化**

```
帮我做结构优化：材料 Li2O，计算类型 OXC；
若有多个备选结构，按最稳定优先；k 点密度 30。
```

可选要点：`formula` 或 `cif_url` 二选一；`selection_mode`（auto/stable/first）、`kpoint_density`；如需高级控制可补充“并把 EDIFF 设成 1e-7，NELM 100”。

- **在已有优化结果上做 SCF**

```
基于我刚才的优化任务，做一次 SCF，精度设为 Accurate。
```

也可以从头指定：
```
给 LiFePO4 做 SCF，计算类型 OXC，k 点密度 35，精度 High。
```

- **提交 DOS 计算**

```
对上一步的 SCF 结果做 DOS，能细一些，k 点扩大到原来的 2 倍。
```

- **提交 MD（单温度或多温度）**

```
在优化结构上做 MD：温度 350 K，步数 2000，系综 NVT，时间步长 1.0 fs。
```

```
做一个多温度 MD 扫描：温度 [300, 400, 500] K，每个 1500 步，输出汇总报告。
```

- **任务管理与帮助**

```
查看我所有任务的进度。
```

```
查询任务 <task_id> 的状态与结果下载地址。
```

```
取消任务 <task_id>。
```

```
给我看下可以自定义哪些 INCAR 参数，以及常用推荐值。
```


## 运行流程（你只需关注关键节点）
1. **提交任务**：你用自然语言描述目标（如“给 Li2O 做结构优化”）。智能体会创建任务并返回一个 `task_id`。
2. **排队与执行**：任务进入队列并执行。你可以随时让智能体“查询任务 <task_id> 进度”。
3. **获取结果**：完成后，智能体会返回：
   - `status/progress`：状态与进度
   - `result_path` 或下载链接：可直接查看/下载结果
   - `result_data`：结构化结果（能量、带隙、DOS 数据、MD 统计等）
   - 对于多温度 MD，还会包含每个温度子任务的汇总信息
4. **继续后续步骤**：通常推荐链式进行：结构优化 → SCF → DOS 或 MD。你也可以基于任一步的 `task_id` 继续后续计算。
5. **管理与追踪**：随时“列出我的任务”“取消任务”，或让智能体整理一份阶段性报告。


## 结果与可交付物
- **结构优化**：优化后的 `CONTCAR`/`POSCAR`、能量与收敛信息、筛选与稳定性统计、可视化报告（HTML/图片）。
- **SCF**：收敛能量、费米能级、电子结构关键数值，作为 DOS/MD 的输入基础。
- **DOS**：总/分波态密度数据（常见为 JSON/图像）、费米能级附近特征、自动生成的 DOS 报告与图。
- **MD**：位移均方（MSD）、径向分布函数（RDF）、能量/温度/压力随时间演化、稳定性评估；支持多温度汇总报告与每个温度的独立结果。
- **任务管理信息**：任务列表、状态、进度、错误信息（若失败）、下载/查看链接。


## 可说得更“专业一点”的参数（可选）
- **calc_type**：比如 `OXC/SSE/ORC/ECAT_OER/ECAT_HER`，表征你的研究方向或任务类别。
- **selection_mode**：`auto/stable/first` 等，控制筛选策略。
- **kpoint_density / kpoint_multiplier**：控制采样密度，DOS 通常更高。
- **precision**：`Normal/High/Accurate`。
- **md_steps / temperature / ensemble / time_step**：MD 常见设置。
- **custom_incar**：当需要手动指定 INCAR（如 `EDIFF`, `NELM`, `LORBIT`, `ISMEAR`, `SIGMA`, `POTIM` 等）。不确定时让智能体“给我推荐合适的 INCAR 设置”。


## 使用建议
- **尽量口语化**：先描述目标，再补充关键限制（材料、精度、温度等）。
- **小步快跑**：先跑一个基础流程（优化→SCF→DOS/MD），再逐步提高精度或加长步数。
- **善用任务管理**：通过“查询/列出/取消”保持对队列的把控。
- **结果复用**：优先在已有优化或 SCF 结果上继续，以减少重复计算。
- **出现失败**：请让智能体“查看任务 <task_id> 的错误信息并给出修正建议”，通常是参数或收敛条件需要微调。
